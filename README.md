# Plant Buddy
A little Tamagotchi desktop app, but you water a plant 🌱​

## Requirements

- **[Node.js](https://nodejs.org/)** (LTS version recommended) — includes npm
- **[Git](https://git-scm.com/)** — to clone the repo

## Running locally

1. Clone the repo:
   ```bash
   git clone https://github.com/maggie-e-matthias/PlantBuddy.git
   cd PlantBuddy
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the app:
   ```bash
   npm start
   ```

The app will open in its own window (no browser UI). You'll need to repeat step 3 (`npm start`) each time you want to run it again — step 2 (`npm install`) is only needed once, or after any dependency changes.
